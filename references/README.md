# Reference sequences

Before running a family, prepare a protein FASTA at:

```text
FAMILY/baits/FAMILY_baits.fasta
```

Use unique identifiers that match the `tree_id` values in the corresponding reference metadata TSV. Keep a record of sequence accessions, source databases, versions and any manual sequence correction.

The reference metadata examples under `configs/examples/` list the accessions used in the initial analyses. Sequence redistribution and provenance should be reviewed before a public release.
