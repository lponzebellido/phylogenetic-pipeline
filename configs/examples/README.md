# Initial-use-case metadata

These small TSV files show how metadata was structured for ABCC, MATE and P3A.

- ABCC includes the five candidate groups accepted after manual review.
- MATE and P3A include reference metadata only because their candidate groups had not been accepted at the inspection point.
- Protein FASTA files and all generated phylogenetic output are intentionally excluded.

These files document the original use cases. They are not universal transporter annotations and should not be copied into a new family without curation.
